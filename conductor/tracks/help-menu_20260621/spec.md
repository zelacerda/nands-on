# Specification: Opção "Help" no Menu e Separadores de Grupo

**Track ID:** help-menu_20260621
**Type:** Feature
**Created:** 2026-06-21
**Status:** Draft

## Summary

Adicionar uma nova opção "Help" no topo do menu de comandos (☰), que abre um modal
resumindo as principais funcionalidades da aplicação, e separar visualmente os grupos do
menu com linhas finas: **Help** | **Import, Export, Clear DB** | **About**.

## Context

NANDS-ON é um simulador de lógica digital 100% no browser, voltado a estudantes e
curiosos. O menu de comandos (☰, topo-direita) é HTML estático em `index.html` com lógica
em `src/main.ts` (vanilla TypeScript) e estilos em `src/style.css`. Os textos vêm de
`src/strings.ts` (fonte única em inglês, aplicada via atributos `data-i18n`). Os modais
seguem o padrão overlay + panel do "About" (`#about-overlay` / `#about-panel`), com fechar
por botão, clique fora e tecla Escape. Hoje o menu lista Import, Export, Clear DB e About,
sem separadores visuais — e não há nenhuma tela de ajuda que resuma o que a app faz.

## User Story

Como um usuário novo do NANDS-ON, quero abrir um "Help" no menu que resuma as principais
funcionalidades da aplicação, para entender rapidamente o que posso fazer sem precisar de
tutorial completo — e quero um menu com grupos visualmente separados para escanear as
opções com mais clareza.

## Acceptance Criteria

- [ ] Existe uma nova opção "Help" no menu de comandos, posicionada **acima** de todas as
      demais (primeiro item, antes de Import).
- [ ] Clicar em "Help" abre um modal que resume as principais funcionalidades da app
      (paleta/arrastar componentes, conectar pinos com fios, alternar entradas e clock,
      criar/editar chips reutilizáveis com "Make", simulação em tempo real, persistência
      local e tutorial interativo).
- [ ] O modal de Help fecha por: botão de fechar, clique fora (no overlay) e tecla Escape —
      consistente com o modal "About".
- [ ] O menu exibe linhas finas separando 3 grupos: **[Help]** | **[Import, Export, Clear
      DB]** | **[About]**.
- [ ] Todos os textos novos (item "Help" e conteúdo do modal) vêm de `src/strings.ts` via
      `data-i18n`, em inglês, seguindo o padrão existente.
- [ ] Abrir o Help fecha o menu de comandos; abrir Help e About não conflitam entre si.

## Dependencies

Depende do código existente: menu de comandos em `index.html`/`src/main.ts`, padrão de
modal do "About", CSS do menu em `src/style.css` e sistema de strings em `src/strings.ts`.

## Out of Scope

- Tradução pt-BR (não há locale pt-BR ainda; o i18n permanece só em inglês).
- Reformulação/refatoração do mecanismo de modais ou do menu além do necessário.
- Conteúdo de ajuda extenso/multi-página, busca, ou vídeos — o Help é um resumo conciso.
- Mudanças no tutorial interativo existente (build NOT from NAND).
- Mudanças nas funcionalidades de Import/Export/Clear DB/About em si.

## Technical Notes

- Reaproveitar o padrão de modal do "About" (`#about-overlay` + `#about-panel`, `role=dialog`,
  `aria-modal`, fechar por botão/overlay/Escape) para o modal de Help.
- Adicionar item `#cmd-help` como primeiro `.menu-item` do `#commands-menu`.
- Separadores: `<div class="menu-divider">` com estilo de linha fina (ex.: `height:1px;
  background:#3a3f4a; margin:4px 0;`) em `src/style.css`, posicionados entre os grupos.
- Conteúdo do modal será rascunhado pelo agente e revisado pelo usuário antes do fechamento
  do track. Bullets concisos sobre os recursos-chave.
- Garantir acessibilidade: `role="menuitem"` no botão Help e `aria-labelledby`/`aria-modal`
  no modal, como no About.
