## Overview

Introduzir um helper puro que recentraliza um `CircuitState` em torno da origem
`{0,0}` — calculando o centro do bounding box dos nós e transladando todas as
posições por um deslocamento arredondado ao grid — e integrá-lo em
`captureDefinition`, atuando sobre a cópia interna já clonada. Por ser lógica de
serialização (correção crítica, fácil de testar), segue TDD com testes
unitários antes/junto da implementação.

## Phase 1: Helper de Recentragem (lógica pura + testes)

Criar a função pura que faz a recentragem, isolada e testável, sem efeitos
colaterais no estado original.

### Tasks

- [x] Task 1.1: Escrever testes para o helper `recenterState` (ou
      `centerNodes`): centro do bounding box vai para `~{0,0}`; deslocamento
      múltiplo de `GRID_SIZE`; translação uniforme preserva posições relativas
      entre nós; idempotência ao recentrar duas vezes; no-op quando não há nós;
      um único nó vai para a origem (snapped).
- [x] Task 1.2: Implementar o helper (em `src/grid.ts` ou `src/chip.ts`):
      computar bounding box sobre `node.pos`, `center = (min+max)/2`,
      `delta = { x: -snapScalar(center.x), y: -snapScalar(center.y) }`, aplicar
      `delta` a cada `node.pos`. No-op se `nodes` vazio.
- [x] Task 1.3: Garantir que o helper opera sobre o estado recebido sem assumir
      que os fios precisam de ajuste (documentar que `barOffset`/offsets de pino
      são relativos).
