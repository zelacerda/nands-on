# Specification: Seleção por Área e Pan com Botão do Meio/Direito

**Track ID:** area-select_20260621
**Type:** Feature
**Created:** 2026-06-21
**Status:** Draft

## Summary

Permitir selecionar múltiplos elementos (chips e I/O) arrastando um retângulo de
seleção, e mudar o gatilho do pan para o botão do meio/direito do mouse (e dois
dedos no tablet), liberando o arraste com botão esquerdo / um dedo para a seleção
por área.

## Context

NANDS-ON é um simulador de lógica digital 100% no browser, com editor de circuitos
em Canvas (Vanilla TS). O input é centralizado em `src/main.ts` por uma máquina de
estados (`Mode = 'idle' | 'pan' | 'dragNode' | 'wire' | 'pinch' | 'dragWaypoint'`)
e uma seleção única (`Selection = { kind: 'node' | 'wire'; id } | null`). Hoje, o
arraste com botão esquerdo em área vazia executa o pan, e dois dedos fazem
pinça (zoom + pan). Esta feature dá ao usuário a capacidade de manipular vários
elementos de uma vez, essencial conforme os circuitos crescem.

## User Story

Como usuário montando circuitos, quero selecionar vários elementos de uma vez
arrastando uma área, para que eu possa movê-los ou removê-los em conjunto
rapidamente.

## Acceptance Criteria

- [ ] Arrastar com o **botão esquerdo** numa área vazia desenha um **retângulo de
      seleção** visível; todos os nós (chips e I/O) contidos no retângulo ficam
      selecionados ao soltar.
- [ ] O **pan** do canvas passa a ser acionado pelo **botão do meio ou direito** do
      mouse (não mais pelo esquerdo).
- [ ] No **touch**, o pan/zoom continua sendo feito com **dois dedos** (pinça); **um
      dedo** numa área vazia desenha o retângulo de seleção.
- [ ] Com múltiplos nós selecionados, é possível **movê-los em conjunto** arrastando
      qualquer nó já selecionado, e **removê-los em conjunto** com Delete/Backspace
      (os fios conectados são removidos em cascata, como já ocorre hoje).
- [ ] Clicar (sem arrastar) numa área vazia **limpa a seleção**.
- [ ] A barra de ações **oculta o botão "Rename"** quando há mais de um elemento
      selecionado (renomear um conjunto não faz sentido); "Delete" continua
      disponível para o grupo.

## Dependencies

Depende do editor de circuitos em Canvas já existente (tracks anteriores):
manipulação de ponteiro (`main.ts`), câmera/pan (`camera.ts`), pinça
(`gesture.ts`), hit-testing (`hittest.ts`), store de nós/fios (`store.ts`) e
renderização (`render.ts`).

## Out of Scope

- Seleção múltipla de **fios** como itens próprios (fio selecionável/movível pelo
  retângulo). Fios conectados a nós selecionados continuam sendo removidos em
  cascata ao deletar os nós.
- O retângulo captura apenas nós cujo corpo esteja contido; não captura fios
  "parcialmente dentro".
- Copiar/colar ou duplicar a seleção múltipla.
- Agrupar a seleção num novo chip diretamente.
- Adicionar/remover da seleção com Shift+clique.
- Alça de redimensionamento da seleção.

## Technical Notes

- Generalizar a seleção única para suportar um **conjunto de nós**
  (`Set<string>` de nodeIds) preservando a seleção única de fio ao clicar.
- Detecção do botão do mouse via `e.button` no `pointerdown` (0 = esquerdo,
  1 = meio, 2 = direito); `contextmenu` já é prevenido no canvas.
- Adicionar um estado de modo para o retângulo (ex.: `'marquee'`) na máquina de
  estados de input.
- Desenhar o retângulo de seleção e o destaque dos nós selecionados em
  `render.ts`.
- Mover o grupo aplicando o mesmo delta (com snap à grade) a todos os nós
  selecionados, reaproveitando a lógica de reset de barra de fios.
- A barra de ações (`updateActionBar`) deve refletir seleção múltipla
  (esconder Rename quando > 1 elemento).
