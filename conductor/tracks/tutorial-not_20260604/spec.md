# Specification: Walkthrough Interativo — Construir um NOT a partir do NAND

**Track ID:** tutorial-not_20260604
**Type:** Feature
**Created:** 2026-06-04
**Status:** Draft

## Summary

Um tutorial **interativo guiado com validação** que ensina, passo a passo, a
construir uma porta **NOT a partir de um NAND** — adicionando componentes, ligando os
fios, alternando o estado da entrada, renomeando entrada/saída e, por fim,
empacotando tudo num chip com o "Make". Cada passo só avança quando o usuário realiza
a ação correta no editor real.

## Context

O **NANDS-ON — From NAND to CPU** ensina a construir uma CPU a partir da porta NAND.
Falta uma porta de entrada didática para quem chega pela primeira vez. Este track
adiciona o walkthrough antecipado no track de branding (`branding-about_20260604`):
no primeiro acesso, o painel de boas-vindas passa a oferecer **"Start Tutorial"**. A
construção do NOT (NAND com as duas entradas no mesmo sinal) é o primeiro "aha" da
jornada NAND→CPU.

## User Story

Como visitante de primeira viagem, quero um tutorial guiado que me faça construir uma
porta NOT a partir de um NAND, para aprender na prática os gestos do editor (criar,
ligar, alternar estado, renomear e empacotar um chip).

## Acceptance Criteria

- [ ] No primeiro acesso, o botão primário do painel de boas-vindas é **"Start
      Tutorial"**; clicá-lo inicia o tutorial. Clicar fora do painel (overlay) ou
      `Esc` fecha **sem** iniciar.
- [ ] Ao iniciar, o espaço de trabalho é **limpo** e um *callout* guia o primeiro
      passo.
- [ ] O tutorial **valida cada ação** e só avança quando feita corretamente, na
      sequência: (1) adicionar uma entrada; (2) adicionar um NAND; (3) adicionar uma
      saída; (4) ligar a entrada às **duas** entradas do NAND; (5) ligar a saída do
      NAND à saída; (6) **alternar o estado** da entrada e ver a saída inverter; (7)
      **renomear** a entrada e/ou a saída; (8) clicar em **"Make"** para empacotar o
      chip NOT.
- [ ] O *callout* mostra o **progresso** (passo N de M) e permite **sair** a qualquer
      momento (botão de sair e `Esc`), preservando o que já foi construído.
- [ ] Ao concluir o último passo, exibe uma **mensagem de conclusão** e encerra o
      tutorial.
- [ ] Todos os textos passam pelo módulo `strings.ts`.

## Technical Notes

- **Detecção sem instrumentar o store:** o loop de render já roda a cada frame e já
  monta `store.toJSON()`/`signalState`. Quando o tutorial está ativo, o passo atual
  tem um predicado `isComplete(ctx)` avaliado a cada frame contra
  `{ store, library, signal, stepStartSnapshot }`; ao satisfazer, avança. Evita
  adicionar um sistema de eventos ao `CircuitStore`.
- **`tutorial.ts`:** lista **declarativa** de passos `{ id, textKey, highlightSelector?,
  isComplete(ctx) }` + estado (`active`, `index`). Lógica de avanço como função pura
  (testável). Predicados de exemplo: nº de nós por tipo; existência de NAND com `in0` e
  `in1` ligados ao mesmo `input.out`; `nand.out → output.in`; mudança do `value` da
  entrada vs. snapshot; `name` definido em entrada/saída; aumento do tamanho da
  biblioteca (Make).
- **`main.ts`:** `startTutorial()` (limpa o espaço, ativa, mostra o passo 0),
  `exitTutorial()`, e no render loop a checagem/avanço. Painel de boas-vindas em modo
  *welcome*: botão primário "Start Tutorial" → fecha + inicia; overlay/`Esc` fecham
  sem iniciar (modo *about* via "?" segue com "Close").
- **UI (DOM):** *callout* com texto do passo, progresso e botão sair; `highlight` via
  classe CSS no botão-alvo da paleta quando o passo definir `highlightSelector`.
- **`strings.ts`:** textos de cada passo, mensagem de conclusão e rótulos ("Start
  Tutorial", "Exit").
- Sem novas dependências.
