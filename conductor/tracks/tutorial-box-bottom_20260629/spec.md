# Specification: Mover Box do Tutorial para a Parte Inferior

**Track ID:** tutorial-box-bottom_20260629
**Type:** Chore
**Created:** 2026-06-29
**Status:** Draft

## Summary

Reposicionar o box de texto do tutorial (`#tutorial-callout`) do topo para a parte inferior
da tela, centralizado e logo acima da barra de edição (`#action-bar`), com uma folga segura
entre os dois, para não cobrir os primeiros chips da paleta em telas verticais de celular.

## Context

O NANDS-ON tem um walkthrough interativo (tutorial "NOT a partir do NAND") cujo texto é
exibido num callout. Hoje esse callout está fixo no **topo** (`#tutorial-callout` em
`src/style.css`: `position: fixed; top: 16px; left: 50%`), região que, em telas verticais
de celular, coincide com os primeiros componentes da paleta — atrapalhando a sua
seleção/arraste justamente durante o tutorial. A barra de ações contextual (`#action-bar`)
fica no rodapé (`bottom: 16px`, botões de 44px).

## Problem Description

Em telas estreitas e verticais (celular), o box do tutorial no topo sobrepõe os primeiros
chips da paleta, impedindo o usuário de selecioná-los/arrastá-los enquanto segue o
tutorial.

## Acceptance Criteria

- [ ] O box do tutorial aparece na **parte inferior** da tela, centralizado, logo acima da
      barra de edição (`#action-bar`), sem sobrepô-la, mantendo uma **folga segura** entre
      os dois.
- [ ] Os primeiros chips da paleta ficam livres (não cobertos pelo box) em telas verticais
      de celular durante o tutorial.
- [ ] O botão de fechar "×" continua acessível e o conteúdo (progresso + texto) permanece
      legível.
- [ ] Em telas maiores (desktop/tablet) o reposicionamento não causa regressão visual.

## Dependencies

Nenhuma. Alteração isolada de CSS de posicionamento em `src/style.css`.

## Out of Scope

- Alterar o conteúdo, os passos ou a lógica (JS) do tutorial.
- Redesenhar o callout (cores, tipografia, tamanho) além do necessário ao reposicionamento.
- Reposicionar a barra de edição (`#action-bar`) ou a paleta.

## Technical Notes

- Trocar a ancoragem de `top: 16px` para o rodapé no seletor `#tutorial-callout`.
- Garantir folga acima do `#action-bar`: a barra ocupa ~60px a partir do fundo
  (`bottom: 16px` + botões de 44px); ancorar o box acima disso (ex.: `bottom: 76px` ou um
  `calc()` com margem extra), de modo que os dois não se toquem quando ambos estiverem
  visíveis.
- Manter `left: 50%` + `transform: translateX(-50%)`, largura e `z-index` atuais.
- Verificação visual em viewport estreita/vertical (celular) e em desktop.
