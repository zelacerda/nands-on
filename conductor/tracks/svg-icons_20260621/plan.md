## Overview

Feature de UI em vanilla TypeScript + Vite. A base é um módulo de ícones que importa os
SVGs via `?raw` e os injeta como markup inline (para herdarem `currentColor`). Em seguida,
cada grupo de controles (menu, barra de ações, barra de edição, Make, modais) é migrado de
texto/emoji para ícone, ajustando markup (`index.html`), lógica (`src/main.ts`), estilos
(`src/style.css`) e strings/atribuição (`src/strings.ts`). Sem testes obrigatórios (UI);
verificação manual no fechamento do track.
