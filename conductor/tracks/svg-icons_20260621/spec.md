# Specification: Ícones SVG (coolicons) nos Botões e Menu

**Track ID:** svg-icons_20260621
**Type:** Feature
**Created:** 2026-06-21
**Status:** Draft

## Summary

Substituir os emojis e rótulos de texto dos botões e do menu por ícones SVG do pacote
**coolicons** (CC-BY, via SVG Repo), normalizados para herdar a cor do tema, e incluir a
atribuição CC-BY exigida no painel "About".

## Context

NANDS-ON é um simulador de lógica digital em vanilla TypeScript + Vite, com UI em DOM
sobre um canvas. Hoje os controles usam texto (Help, Import, Export, About, Edit, Rename,
Delete, Save, Cancel, Make) e emojis (☰ no menu, ⚠️ no Clear DB). Os ícones ficam em
`src/assets/icons/` (13 SVGs do coolicons), todos no padrão `fill="none"` +
`stroke="#000000"` e `width/height="800px"`. O projeto já usa imports estilo Vite
(`?raw`), tem `"types": ["vite/client"]` no tsconfig e textos centralizados em
`src/strings.ts` (inglês, aplicados via `data-i18n`/`data-i18n-attr`). A licença CC-BY
exige atribuição visível ao usuário, que será adicionada à seção "Credits" do About.

## User Story

Como usuário do NANDS-ON, quero que os botões e o menu usem ícones claros e consistentes
em vez de texto/emoji, para reconhecer as ações mais rápido e ter uma interface mais limpa
e profissional — em desktop e em telas pequenas.

## Acceptance Criteria

- [ ] Todos os SVGs em `src/assets/icons/` usam `stroke="currentColor"` (sem cor fixa) e
      escalam pelo CSS (sem `width/height` fixos de 800px), herdando a cor do tema.
- [ ] **Menu** — o botão ☰ usa o ícone `hamburger-lg` (só ícone); os itens Help, Import,
      Export, Clear DB e About usam ícone + rótulo (`help`, `file-upload`, `file-download`,
      `triangle-warning`, `info`).
- [ ] **Barra de ações** — Edit, Rename e Delete viram só ícone (`edit-pencil-01`, `text`,
      `trash-full`), em **botões circulares**, com `aria-label` para acessibilidade.
- [ ] **Barra de edição** — Save e Cancel viram só ícone (`check-big`, `close-md`) com
      `aria-label`.
- [ ] **Make** usa ícone `add-plus` + rótulo.
- [ ] **Modais** — os botões primários do About (Close/Start Tutorial) e do Help (Got it)
      exibem o ícone `check-big` junto ao texto.
- [ ] A atribuição CC-BY é exibida no painel About: "Vectors and icons by Krystonschwarze
      in CC Attribution License via SVG Repo" (com links para o coolicons e o SVG Repo).
- [ ] Build, typecheck e lint passam; nada de texto/emoji remanescente nos elementos
      acima (exceto os rótulos que permanecem ao lado do ícone).

## Dependencies

Depende do código existente: menu/modais (`index.html`, `src/main.ts`), barra de ações e de
edição, botão Make, CSS (`src/style.css`), sistema de strings (`src/strings.ts`) e dos SVGs
já adicionados em `src/assets/icons/`. Sem dependência de outras tracks.

## Out of Scope

- **Reordenação de componentes por arrastar** — o ícone `drag-vertical` é mantido no repo
  para uso futuro, mas a funcionalidade (e o cabeamento do ícone) fica para outra track.
- Ícones para elementos sem ícone correspondente além dos mapeados (ex.: botões IN/OUT da
  paleta permanecem como estão).
- Tradução pt-BR (i18n segue só em inglês).
- Biblioteca/sprite system de ícones ou dependências novas — uso direto dos SVGs via Vite.

## Technical Notes

- **Normalização dos SVGs:** trocar `stroke="#000000"` → `stroke="currentColor"` e remover
  os atributos `width`/`height` fixos (manter `viewBox`), controlando o tamanho via CSS.
- **Carregamento:** importar os SVGs como string com `?raw` e injetar via `innerHTML` em um
  wrapper, permitindo estilizar com `currentColor`. Centralizar num módulo
  (ex.: `src/icons.ts`) com um registro nome→markup e um helper de inserção.
- **Markup icon + texto:** para itens que mantêm rótulo (menu, Make, modais), estruturar o
  botão com `<span>` do ícone + `<span data-i18n="...">` do rótulo, para `applyStrings` não
  sobrescrever o ícone.
- **Icon-only:** usar `data-i18n-attr="aria-label:..."` (reaproveitando chaves existentes
  como `action.edit`, `action.rename`, etc.) e injetar só o ícone.
- **Barra de ações circular:** os botões Edit/Rename/Delete ganham formato circular
  (largura = altura, `border-radius: 50%`, ícone centralizado), para um visual mais
  elegante agora que não têm rótulo. A barra de edição (Save/Cancel) permanece com o
  formato atual, salvo pedido em contrário.
- **Atribuição:** adicionar chaves em `src/strings.ts` e um `<p>` no About espelhando o
  padrão "Inspired by <a>…</a>" (spans `data-i18n` + âncoras), pois `data-i18n` define
  `textContent` e não renderiza HTML.
- `noUnusedLocals` é estrito: o registro de ícones deve referenciar os imports; ícone não
  cabeado (`drag-vertical`) entra no registro para não virar import órfão.
