Os ícones SVG nesta pasta são distribuídos sob **Creative Commons Attribution
(CC-BY)**. A licença CC-BY exige que o crédito ao autor seja exibido de forma
visível ao usuário — neste projeto, a atribuição aparece no painel **About**.

- **Pacote/coleção:** coolicons

- **Fonte:** https://github.com/krystonschwarze/coolicons?ref=svgrepo.com
- **Distribuído via:** SVG Repo — https://www.svgrepo.com/
- **Licença:** CC Attribution License (CC-BY)
- **Modificações:** `stroke="#000000"` substituído por `stroke="currentColor"` para
  que os ícones herdem a cor do tema; dimensões controladas via CSS.
